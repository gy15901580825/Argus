# Upcoming probes

New probes written by the Argus maintainers run first in [AT Helper](https://at-helper.com), the hosted service built on Argus. Each one is added to Argus 30 days later under the same Apache 2.0 license. The delay is fixed at 30 days and is never extended.

The delay covers only probes that are plain YAML and run in hosted mode. Engine changes, test environments, and probes that need them come to Argus right away. Probes contributed by others are merged without delay. Nothing already in Argus is ever removed or relicensed.
